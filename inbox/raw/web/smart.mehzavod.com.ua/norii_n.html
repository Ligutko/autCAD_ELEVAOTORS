Устройство и работа

Нория состоит из следующих основных узлов, соответственно для марок Н-5 (рис.1), Н-10 (рис.2), Н-20 (рис.3): башмака 1, головки 2, труб норийных гладких 3 и 4, трубы норийной натяжной со смотровым люком 6, трубы для установки датчика подпора и датчиков контроля сбегания ленты 7, трубы с аспирационным патрубком 8, двух труб для установки взрыворазрядного устройства 9-по заказу потребителя, трубы для датчиков контроля сбегания ленты 11. В качестве тягового органа применяется лента с рабочим органом - ковшами 5.

Нория Н-10х2 состоит из таких узлов (рис.4): двух башмаков симметричного исполнения 1 , головки 2, труб норийных гладких 3 и 4, двух труб натяжных со смотровым люком 6, двух труб для установки датчика подпора и датчиков контроля сбегания ленты 7, двух труб с аспирационным патрубком 8, четырёх труб для установки взрыворазрядных устройств 9-по заказу потребителя, двух труб для датчиков контроля сбегания ленты 11 и двух лент с ковшами 5.

Нория Н-5х2 состоит из следующих основных узлов (рис. 5): башмака 1, головки 2, труб норийных гладких 3 и 4, трубы норийной натяжной со смотровым люком 6, трубы для датчиков подпора 7, трубы с аспирационными патрубками 8, 2 труб для установки взрыворазрядных устройств 9-по заказу потребителя. В качестве тягового органа применяются две ленты с рабочим органом - ковшами 5.

Башмак нории состоит из сварного кожуха и барабана. Вал с барабаном установлен в корпуса подшипников, выполненные в виде подвижных щёк винтового натяжного устройства. Для контроля скорости, пробуксовки и поперечного порыва ленты нории комплектуются датчиком, который устанавливается на валу башмака.

Головка нории состоит из корпуса, состоящего из верхней и нижней частей, труб норийных, барабана, промежуточной опоры, привода, патрубка выгрузочного, ограждений. Для норий Н-5, Н-10,Н-5х2 приводом барабана служат две ременные передачи (от двигателя к промежуточной опоре и от промежуточной опоры к барабану). Для норий Н-20 и Н-10х2 приводом служат ременная передача (от двигателя к промежуточной опоре) и цепная передача (от промежуточной опоры к барабану). В нижней части корпуса имеются смотровые люки.

Патрубки для установки взрыворазрядного устройства устанавливаются на головке нории.

Для устранения обратной сыпи материала в нижней части головки смонтирован регулирующий козырёк.

Зазор между корпусом головки и корпусами подшипников надежно загерметизирован.

Основным тяговым и рабочим органом нории является лента норийная с закреплёнными ковшами. Лента проходит в норийных трубах, огибает приводной и натяжной барабаны головки и башмака. Концы ленты должны быть соединены с помощью уголков поз10 или внахлёст на один шаг ковшей.

Норийные трубы являются кожухами для ленты и выполнены в виде квадратных труб с фланцами для крепления между собой (для нории Н-5х2 трубы прямоугольные с перегородкой). Над башмаками устанавливаются трубы с датчиком подпора для предотвращения завала транспортируемым продуктом. Для выполнения аспирации нории устанавливаются трубы с аспирационным патрубком. Нории комплектуются трубами для установки взрыворазрядных устройств (по заказу). Для периодического осмотра состояния ковшей и ленты и для заправки и стяжки ленты устанавливается специальная смотровая труба.

Зерно по самотёчным трубам поступает в приёмный патрубок башмака нории, а затем подхватывается ковшами и подаётся на установленную высоту до головки нории, где под действием центробежного ускорения происходит разгрузка ковшей и далее зерно по самотёкам направляется согласно технологической схемы.
