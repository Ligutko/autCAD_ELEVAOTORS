# 🎨 PDF to AutoCAD Converter для Елеваторів

## 📋 Опис

Автоматичний конвертер технологічних схем елеваторів з PDF у DXF/DWG формат для AutoCAD.

**Можливості:**
- ✅ Перетворює кожну сторінку PDF в окремий DXF файл
- ✅ Автоматично малює силоси МСВУ 220.13.В12
- ✅ Автоматично малює норії (bucket elevators)
- ✅ Автоматично малює транспортери (конвеєри)
- ✅ Створює професійні шари (Layers)
- ✅ Підтримує AutoCAD 2010+
- ✅ Опціональний автоматичний імпорт в AutoCAD

---

## 🚀 Швидкий старт

### Варіант 1: Через BAT файл (найпростіше)

1. Запусти `КОНВЕРТУВАТИ_PDF_В_AUTOCAD.bat`
2. Дочекайся створення DXF файлів
3. Файли будуть в папці `autocad_drawings/`

### Варіант 2: Через Python

```bash
python pdf_to_autocad_converter.py
```

## 🔧 Технічні деталі

### Шари (Layers)
- **EQUIPMENT** (червоний) - загальне обладнання
- **SILOS** (жовтий) - силоси
- **CONVEYORS** (пурпурний) - транспортери
- **TEXT** (зелений) - текст і позначення
- **DIMENSIONS** (блакитний) - розміри

### Формат DXF
- Версія: AutoCAD 2010 (AC1024)
- Кодування: UTF-8
- Одиниці: мм

## 📖 Як відкрити в AutoCAD

### Метод 1: Автоматичний імпорт
```
Запусти конвертер → вибери 'y' при питанні про імпорт
```

### Метод 2: Ручне відкриття
1. Відкрий AutoCAD
2. File → Open
3. Вибери DXF файл з папки `autocad_drawings/`

### Метод 3: Через команду DXFIN
1. В AutoCAD введи: `DXFIN`
2. Вибери потрібний DXF файл

## 🛠 Налаштування

### Змінити вихідну папку
Відредагуй `pdf_to_autocad_converter.py`:

```python
converter = PDFToAutoCADConverter(output_dir="моя_папка")
```

### Додати своє обладнання
Відредагуй метод `create_page_data()`:

```python
{
    "type": "silo",
    "tag": "МСВУ-7",
    "x": 250,
    "y": 50,
    "diameter": 22000,
    "height": 21422
}
```

## 🐛 Можливі проблеми

### Помилка: "AutoCAD не знайдено"
**Рішення:** Переконайся що AutoCAD запущений перед імпортом

### Помилка: "EOF when reading a line"
**Рішення:** Це нормально при запуску без інтерактивного вводу. DXF файли вже створені!

### Файли створені, але порожні
**Рішення:** Перевір що у `create_page_data()` є дані обладнання

## 🎓 Приклади використання

```python
converter = PDFToAutoCADConverter()
dxf_files = converter.convert_all_pages()
```

### Створити + автоімпорт
```python
converter = PDFToAutoCADConverter()
dxf_files = converter.convert_all_pages()
converter.import_to_autocad(dxf_files)
```
