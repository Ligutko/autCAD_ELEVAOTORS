## По пунктах

**R1. Час ходу засувок.**
- Лубнимаш часу ходу не дає ні на сайті, ні в каталозі.
- Знайдено два аналоги рейкових засувок з мотор-редуктором: серія У8-ТЭА — 6 с на □200–□350 (та сама таблиця у двох постачальників), серія ЭЗР — 6–10 с на □200–□450.
- 0,18 кВт проти 0,25 кВт на час не впливає: його задає передаточне число.
- Для ядра: 6 / 6 / 7 с для ТЕА-300 / ТЕА-04М / ТЕА-05М. Перевірки блокувань варто прогнати ще й з 10 с.
- Не знайдено: паспортів Brock, Sukup, Chief, Tornum, Symaga зі швидкістю ходу. У Symaga «Technical Data» є лише «electric, 2 detectors», без часу.

**R2. Розгін, вибіг, пуск.**
- Прямого часу розгону для норії чи ТЦС ніде немає. Є загальне правило ABB: прямий пуск звичайного механізму — 2–4 с, м’який пуск конвеєра — рампа 10 с.
- Є затримки реле швидкості: 4B — 10 с за замовчуванням (Mk2: 5 / 15 / 30), Milltronics — 0–60 с. Отже виробники датчиків закладають розгін за 10 с.
- Норма з числом одна: НПАОП 15.0-1.01-17 вимагає сирену за 15–20 с до дистанційного пуску. Норми з числом для інтервалу між пусками механізмів не знайдено: наступний механізм запускається, коли попередній вийшов на швидкість.
- Вибіг двигуна оцінено розрахунком (judgment): секунди. Головна затримка зупинки — вибіг зерна L / v, його ядро вже рахує.
- Де шукати далі: паспорт норії Лубнимаша (тип пускача в шафі керування); проєкт автоматизації (розділ ЕМ або АТХ) у ПРОМАГРОПРОЕКТ.

**R3. Сушарка.**
- (а) Для пшениці таблиця STRAHL має лише режим 20→15. Для кукурудзи є п’ять режимів. Інші режими пшениці пораховано через планові тонни: Кв і Кк з Інструкції 9-3-82, взяті з калькулятора «Аудитэнерго» — вторинне джерело, першоджерело не знайдено. Перевірка на рядках кукурудзи STRAHL: відхилення від −4 % до −27 %, метод консервативний.
- (б) Час перебування зерна для пшениці 20→15 — 1,4 год: 41 т у сушарці / 29,3 т/год. Лубнимаш СШ-50 дає 1,7 год. В описі STRAHL написано «2,5–4 год», але це текст про кукурудзу. Конфлікт записано.
- (в) Питома витрата тепла — ≈ 3 300–3 500 кДж/кг води. Рахував з рядків кукурудзи STRAHL: 1,16 м³/(%·т) в усіх рядках, те саме, що в Лубнимаша (1,1–1,2). OMAFRA для сушарки змішаного потоку дає ≈ 4 500.
- **Знахідка:** рядок пшениці в таблиці STRAHL внутрішньо неузгоджений. Сухий вихід 24,4 не сходиться з балансом маси 27,58, а газ 104 м³/год дає 2 150 кДж/кг, що фізично неможливо. Для ядра брати баланс маси і ≈ 170 м³/год.
- Додатково: перед пуском сушарки — продування вентиляторами 3 хв.

**R4. Залишок у силосі.**
- Готової частки для МСВУ, Symaga, Brock, GSI не знайдено. Єдине число — «понад 25 % місткості» з галузевого журналу (2020), для силосу невідомої схеми.
- Пораховано геометрично для реальної схеми отворів МСВУ 220: центр і 6 бічних в один ряд з кроком 3,25 м. Кут витікання взяв ≈ 34° (EN 1991-4 φr; «при обваленні» 34–36° за ЛНТУ). Результат: ≈ 18,5 % ≈ 890 т після всіх отворів і ≈ 28 % після одного центрального.
- Кут 25–28°, що є в моделі, — це кут насипання. Для верхнього конуса він правильний, для залишку занижений.
- Скрипт розрахунку наведено нижче. Результат — FINDING для перевірки, не факт.
- Де шукати далі: паспорт МСВУ або інструкція з експлуатації Лубнимаша (розділ про вивантаження); фото зачистки МСВУ 220.

**R5. Старий приймальний блок.**
- У документах об’єкта немає т/год ні для H2, T1, T2, T4, T6, ні для сепаратора 5. Перевірено OCR арк. 1 і специфікації арк. 8–12. На кресленні підписано лише H1 / H3 / H4 — 100 т/год.
- Аналоги класу:
  - сепаратор Лубнимаш АСК — 100 т/год;
  - правило Лубнимаша для сепараторів: мінус 5 % продуктивності за кожен 1 % вологи понад 14 %, мінус 2 % за кожен 1 % домішок понад 4 %;
  - допоміжні контури в реальному проєкті з обладнанням Лубнимаша (НОС-2436) — 50 т/год.
- **Знахідка:** якщо сепаратор 5 класу 100 т/год, мокре приймання при вологості 20 % обмежене ≈ 70 т/год.
- Де шукати далі: генплан і паспорти існуючої частини в замовника (вже в `process.gaps`).

**R6. Розвантаження самоскида.**
- Норми для самоскида в проїзну яму немає. ВНТП 05-88 нормує лише автомобілерозвантажувачі: за табл. Т-5.2 на 20 т виходить 4,8 хв.
- Аналоги: розвантажувач — 3–5 хв на авто (нахил платформи 30 т — 60 с); самоскидний напівпричіп — 5–10 хв (блог дилера); проїзна платформа Bruks — 8–9 хв між авто.
- Для ядра: висипання 5 хв (3–10), заїзд і виїзд по 1 хв.
- Темп приймання задає T1 зі 100 т/год: 2,5–4 авто на годину.

**R7. HMI.**
- ANSI/ISA-101.01 і «The High Performance HMI Handbook» платні, текстів немає.
- Використано статтю Hollifield, співавтора книги й учасника комітету ISA-101, і Rockwell PROCES-WP023, прямо узгоджений з ISA-101.
- Принципи:
  - сірий фон, приглушені кольори;
  - колір — лише для тривог, ненормальних станів і, стримано, для живих даних (темно-синій або темно-зелений);
  - стан обладнання — яскравістю заливки плюс слово стану, не червоним і зеленим;
  - тривога — окремий індикатор з формою, кольором і текстом;
  - пріоритети тривог: червоний, помаранчевий, жовтий, пурпуровий.
- Hex-коди в таблиці — з палітри Rockwell, це приклад, а не вимога норми.
- Для пульта: trip → Urgent, червоний; alarm → High або Medium; стан двигуна `off / starting / run / stopping / fault` → `#808080 / #93C2E4 / #F0F0F0 / #93C2E4 / чорний`.

## Скрипт залишку (R4, rec_94b89ff8, rec_94f7de71)

```python
import numpy as np, math
R=11.0; offs=[-9.75,-6.5,-3.25,0,3.25,6.5,9.75]; n=1500
xs=np.linspace(-R,R,n); dx=xs[1]-xs[0]; X,Y=np.meshgrid(xs,xs); inside=X**2+Y**2<=R*R
def resid(theta, outlets):          # outlets: (x, y, half_size)
    t=math.tan(math.radians(theta)); Z=np.full(X.shape,1e9)
    for ox,oy,h in outlets:
        d=np.hypot(np.maximum(abs(X-ox)-h,0), np.maximum(abs(Y-oy)-h,0)); Z=np.minimum(Z,d*t)
    return (Z*inside).sum()*dx*dx    # m3; частка = V/6381, маса = V*0.75
center=[(0,0,0.2)]; allo=[(o,0,0.2 if o==0 else 0.175) for o in offs]
```
