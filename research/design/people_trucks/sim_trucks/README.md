# T11a. Вантажівки з відкритих симуляторів

Шукав реалістичні моделі європейського тягача, самоскида або зерновоза для кадру поруч із силосами. Білий список ліцензії саме меша: MIT, Apache-2.0, CC0, CC-BY. Файл мав качатися прямим HTTP без облікового запису і бути не більшим за 100 МБ. Sketchfab людина вже перевірила: безкоштовних придатних моделей немає, API без токена відповідає 401.

**Висновок: реалістичну модель під ці умови не знайдено. Нічого не скачано.** У білому списку є лише іграшкові low-poly (той самий клас, що вже записаний у `nologin_assets.md`). Найближчі реалістичні сітки або закриті іншою ліцензією, або існують лише як `.uasset` у пакунку, більшому за 100 МБ.

SHA-256 порожній, бо локальних файлів немає. Git blob SHA і digest релізу GitHub у таблицю хешів не підставляв.

## Чого не знайдено

- Зерновоза (кузов під зерно, європейський сідельний тягач із причепом-зерновозом) немає в жодному джерелі з білого списку.
- Вихідного FBX або OBJ кузова CARLA `european_hgv` / `firetruck` / `carlacola` поза `.uasset` немає. Допоміжні `VehicleSkeleton.rar` і `LicensePlate.rar` — не кузов.
- Відкритого самоскида або сідельного тягача з ліцензією рівно MIT, Apache-2.0, CC0 або CC-BY, файлом ≤ 100 МБ і без логіну, немає.
- GitHub-пошук за «semi truck glb», «tractor trailer fbx» і «dump truck gltf» не дав такого файлу. Пошук коду GitHub вимагає авторизації, його не викликав. Репозиторії на кшталт `Hyperfyzz-truck.glb` (148 КБ) — дрібні сцени, не симуляторна вантажівка.

## Що навмисно не завантажував

Папку моделі з `LICENSE.txt` і `SOURCE.txt` не створював: жоден файл не пройшов усі умови одразу (реалістичний клас, білий список ліцензії меша, прямий HTTP, ≤ 100 МБ, не `.uasset`/`.umap`).

Найближчий промах за геометрією — Chrono MAN Kat 1: окремі OBJ шасі, диска й шини, близько 1 МБ на кузов, без логіну. Відсіяв через BSD-3-Clause і прив'язку даних до книжки 1999 року.

Другий промах — esmini `semi_tractor`: правильний клас машини, але меш лежить у Dropbox-архіві OSGB, і ліцензію цього пакунка не встановлено.

## Підсумок

Реалістичну модель європейського тягача, самоскида чи зерновоза з ліцензією MIT, Apache-2.0, CC0 або CC-BY, файлом ≤ 100 МБ і прямим HTTP без облікового запису не знайдено.
Жодного меша не скачано: у `sim_trucks` лежить лише цей звіт, без `LICENSE.txt` і `SOURCE.txt`.
CARLA `european_hgv`, `firetruck`, `carlacola` і `MiningTruck` є лише як `.uasset` у контенті CC-BY 4.0; вихідного FBX/OBJ кузова немає, пакунок контенту більший за 100 МБ.
Найближчі реалістичні OBJ — Project Chrono MAN Kat 1 (5t/7t/10t): колеса окремо від шасі, але ліцензія репозиторію BSD-3-Clause, а дані кузова віднесені до книжки Heel Verlag 1999.
openx-assets (38 805 006 Б, без логіну) містить реалістичні легкові, фургон і пікапи, не тягач; ліцензія мешів `MPL-2.0 AND CC-BY-4.0`, поза білим списком.
esmini називає `semi_tractor`, `semi_trailer` і `truck_yellow` як `.osgb` на Dropbox; ліцензію цих мешів як CC-BY, CC0, MIT або Apache не підтверджено.
LGSVL забороняє комерційне використання, BeamNG закритий, AirSim і безкоштовні зразки Unreal — це `.uasset`, NVIDIA Isaac/Omniverse не під CC/MIT.
Єдині меші білого списку — іграшкові: Godot Truck Town (MIT, GLB 46 544 Б, окреме колесо, близько 140–240 трикутників), Kenney, Quaternius, CesiumMilkTruck; зерновоза немає.
