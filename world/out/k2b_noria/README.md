Скрипт: `python world/build/k2b_noria.py` (`--quick` — чернетка). Код: `world/kit/noria_n100.py`, підписи: `world/kit/common.py` (`labels`, `face_labels`).

## Кадри

- `noria_head_cutaway.png` — голова без передньої кришки: барабан, стрічка, ковші, датчики, підписи
- `noria_head_closed.png` — голова закрита: мотор-редуктор на валу 22 кВт, реактивна тяга, вибухорозрядник
- `noria_boot_cutaway.png` — башмак у приямку без кришки: крильчастий барабан, натяжка, датчик швидкості

У сцені кришки — окремі об'єкти `H5_NORIA_HEAD_COVER` і `H5_NORIA_BOOT_COVER`: сховати їх — і вузол у розрізі. Підписи — колекція `LABELS_H5`, вмикається окремо.
Ковші розставлені по стрічці параметром `phase` (метри): це основа для анімації руху (етап D2).
