# K1. Силос МСВУ 220.13.В12 зовні

Скрипт: `python world/build/k1_silo.py` (`--quick` — чорновий рендер 960×540).
Код вузла: `world/kit/silo_msvu220.py`. Спільні матеріали, небо, меші: `world/kit/common.py`.

## Що є в моделі і звідки числа

| Вузол | Значення | Джерело |
|---|---|---|
| Діаметр | 22.0 м | PDF p.6, LUB |
| Пояси | 13 × 1152 мм, верх стіни 14.976 м | LUB таблиця серії |
| Гофра | крок 64 мм, 18 хвиль на пояс, глибина 13 мм | LUB (крок), EST (глибина) |
| Лист | 3.0 мм знизу → 1.0 мм зверху, справжня товщина в сітці | LUB діапазон 1–3 мм, розподіл EST |
| Ребра жорсткості | 80 шт., омега-профіль 160×75 мм, 3 мм | PDF p.6 (кількість), LUB (омега 1–6 мм), EST (переріз) |
| Листи в поясі | 20 по 3.46 м, вертикальні шви зі зсувом через пояс | EST |
| Болти | M10, головка s = 16 мм, k = 6.4 мм, ~26 900 шт. на силос | STD ISO 4017, крок EST |
| Дах | конус 30°, 80 ребер, звис 0.22 м, лист 1.5 мм | LUB (кут), PDF p.6 (ребра), EST |
| Верх | кільце Ø1.3 м, патрубок Ø400 до +21.422 | PDF p.8, LUB, EST |
| Фундамент | кільце R 11.6 м, 0.6 м, верх на +0.600 | PDF p.4, p.6 |
| Анкерні опори | під кожним ребром: 2 косинки, плита, гайка | EST |
| Вентилятори аерації | 4 шт. під 45°, 11 кВт, равлик Ø1.25 м, двигун, рама, плита | PDF p.2 (кількість, положення), каталог (кВт), EST (габарит) |
| Драбина | клітка, щаблі 300 мм, ширина 500 мм, обручі з 2.2 м через 0.9 м; драбина по даху з поручнем 1.0 м | STD ISO 14122-4 |
| Люк у стіні | 700 × 1100 мм у рамі | EST |
| Дахові дефлектори | 2 шт. | EST (каталог дає даховий вентилятор, тип ще не вибрано) |

Матеріали процедурні: оцинковка з «квітами» цинку, кожен лист свого відтінку, патьоки від дощу, пил біля землі; бетон; гравій з сухою травою. Небо фізичне (Nishita), сонце 32° над обрієм.
