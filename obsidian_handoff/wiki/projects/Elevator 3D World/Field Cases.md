# Field Cases

Повернутись: [[00 Handoff]]

Аварії з об'єктів нашої монтажної команди — сценарії роликів «як сталося / як треба».

1. Удар БпЛА: зруйновано верхні пояси й дах; ремонт не показуємо.
2. Неправильно змонтовані термопідвіски → зерно пріє, гниє. → [[K5 Silo Interior]]
3. Мало / не там вентиляторів аерації → мертві зони, псування. → [[K5 Silo Interior]]
4. Незатягнуті болти, стики без герметика → вода всередину.
5. Помилка інженерно-геологічних вишукувань → мілкий фундамент, пливун, крен.
6. Вкорочені монтажниками анкерні болти.
7. Проєкт від людей без досвіду → деталі не сходяться, «халтура» на монтажі.

Монтаж: основа → каркас → зверху вниз (імовірно домкратний, підтвердити — [[06 Open Questions]]). Цілий рік.
