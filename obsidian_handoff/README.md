# obsidian_handoff — пам'ять проєкту для Obsidian

Ваше сховище `VAULT/` навмисно виключене з git, тому нотатки лежать тут, щоб не перезаписати ваші.

Як перенести:
1. Скопіюйте вміст `obsidian_handoff/wiki/` у `VAULT/wiki/` (нові файли, нічого не замінюють).
2. У вашій нотатці `VAULT/wiki/domains/3D Elevator Agentic Pipeline.md` додайте рядок `[[Elevator 3D World MOC]]` — це вхід у проєкт.

Вхід для нового агента: `wiki/projects/Elevator 3D World/00 Handoff.md`.
Нотатки пов'язані `[[посиланнями]]`, мають YAML-властивості (`type`, `status`, `updated`, `code`, `tags`) для Dataview. Джерело правди — репозиторій.
