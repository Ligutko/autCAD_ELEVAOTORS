# БЕЗПЕЧНА СИСТЕМА МАСШТАБУВАННЯ - ІНСТРУКЦІЯ

## ЯК ЦЕ ПРАЦЮЄ

Система автоматично:
1. **Зберігає оригінал** - створює незмінну копію вихідного файлу
2. **Відстежує стан** - записує всі виконані операції в JSON
3. **Запобігає повторенню** - перевіряє чи операція вже застосована
4. **Створює резервні копії** - зберігає результати з timestamps

## СТРУКТУРА ДИРЕКТОРІЙ

```

```

## ОСНОВНІ ФАЙЛИ

### 1. STATE_MANAGER.py
**Призначення**: Управління станом та файлами

**Функції**:
- `preserve_original()` - зберігає оригінал в ORIGINALS/
- `create_working_copy()` - створює робочу копію
- `can_apply_operation()` - перевіряє чи можна застосувати операцію
- `record_operation()` - записує виконану операцію
- `mark_processed()` - позначає файл як повністю оброблений
- `save_result()` - зберігає результат в RESULTS/

### 2. SAFE_RESIZE_SYSTEM.py
**Призначення**: Головна система масштабування з перевірками

**Операції**:
1. `delete_red_lines` - видалення червоних ліній
2. `scale_silo_3` - масштабування силосу #3 (1.2x)
3. `scale_silo_4` - масштабування силосу #4 (1.2x)
4. `scale_silo_5` - масштабування силосу #5 (0.8x)
5. `scale_silo_6` - масштабування силосу #6 (0.8x)
6. `add_7th_silo` - додавання 7-го силосу (копія #6)
7. `draw_connections` - малювання червоних з'єднань

**Кожна операція**:
- Перевіряється чи вже застосована
- Записується в state після виконання
- Не може бути виконана повторно

## ЯК ЗАПУСТИТИ

### Перший запуск (обробка нового файлу):
```bash
python SAFE_RESIZE_SYSTEM.py
```

Система автоматично:
1. Створить ORIGINAL копію
2. Створить WORKING копію
3. Виконає всі операції
4. Збереже результат в RESULTS/
5. Позначить файл як оброблений

### Спроба повторного запуску:
```bash
python SAFE_RESIZE_SYSTEM.py
```

Результат:
```
❌ ОБРОБКА НЕМОЖЛИВА - файл вже оброблено або операції застосовано
   Використайте нову копію оригіналу для повторної обробки.
```

### Повторна обробка (якщо потрібно):
1. Створити нову копію з ORIGINALS/
2. Перейменувати її (наприклад, FRESH_ORIGINAL_V2.dxf)
3. Змінити `source_file` в SAFE_RESIZE_SYSTEM.py
4. Запустити знову

## ЩО ЗАПОБІГАЄ ПОВТОРНОМУ МАСШТАБУВАННЮ

### 1. Перевірка перед кожною операцією
```python
if not self.state_manager.can_apply_operation(file_key, "scale_silo_3"):
    print("⏭ Пропускаю (вже виконано)")
    return 0
```

### 2. Запис після виконання
```python
self.state_manager.record_operation(file_key, "scale_silo_3", {
    "scale": 1.2,
    "objects_scaled": 24
})
```

### 3. Блокування повторної обробки
```python
if self.state_manager.is_processed(file_key):
    print("❌ ФАЙЛ ВЖЕ ОБРОБЛЕНО!")
    return False
```

## ПЕРЕВАГИ СИСТЕМИ

✅ **Ніколи не втратите оригінал** - автоматичне збереження в ORIGINALS/

✅ **Запобігає помилкам** - перевірка стану перед кожною операцією

✅ **Повна історія** - всі операції записані з timestamps

✅ **Можна перевірити стан** - читайте processing_state.json

✅ **Безпечні експерименти** - завжди можна повернутися до оригіналу

✅ **Автоматичні backup** - результати з timestamps в RESULTS/

## ВАЖЛИВО

⚠️ Файли в ORIGINALS/ - **НЕ РЕДАГУВАТИ ВРУЧНУ!**

⚠️ Файли в WORKING/ - тимчасові, будуть перезаписані

⚠️ processing_state.json - **НЕ РЕДАГУВАТИ ВРУЧНУ!**

✅ Результати беріть з RESULTS/ - вони з timestamps

## СКИДАННЯ СТАНУ (ПОВНЕ ОЧИЩЕННЯ)

Якщо потрібно почати з нуля:

```bash

```
