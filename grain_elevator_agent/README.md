# Grain Elevator P&ID Generator - AI Agent System

## Огляд системи

Багатоагентна AI система для автоматичної генерації технологічних схем зернових елеваторів в AutoCAD 2026.

### Архітектура (Multi-Agent System)

```
┌─────────────────────────────────────────────────────────────┐
│                    ORCHESTRATOR AGENT                        │
│              (Координація та управління)                     │
└────────────────────┬────────────────────────────────────────┘
                     │
        ┌────────────┼────────────┐
        │            │            │
        ▼            ▼            ▼
┌──────────────┐ ┌──────────────┐ ┌──────────────┐
│  ANALYZER    │ │  GENERATOR   │ │  VALIDATOR   │
│    Agent     │ │    Agent     │ │    Agent     │
└──────────────┘ └──────────────┘ └──────────────┘
        │            │            │
        │            │            │
        ▼            ▼            ▼
┌──────────────────────────────────────────────────┐
│          AutoCAD MCP Server Interface            │
│         (LISP Commands via Python API)           │
└──────────────────────────────────────────────────┘
                     │
                     ▼
            ┌─────────────────┐
            │  AutoCAD 2026   │
            │   (DWG Output)  │
            └─────────────────┘
```

## Компоненти системи

### 1. Analyzer Agent
**Призначення:** Парсинг технічної документації та екстракція параметрів

**Функції:**
- Читання PDF/зображень схем
- OCR розпізнавання міток та параметрів
- Екстракція координат обладнання
- Виявлення зв'язків між елементами
- Побудова граф-структури схеми

**Вхідні дані:**
- PDF з технологічною схемою
- Зображення P&ID діаграм
- Текстові описи обладнання

**Вихідні дані:**
- Структурований JSON з параметрами:
  ```json
  {
    "silos": [
      {"id": "1", "type": "MCBY_220.13/B12", "diameter": 22000,
       "volume": 6381, "position": {"x": 0, "y": 0}}
    ],
    "conveyors": [...],
    "elevators": [...],
    "connections": [...]
  }
  ```

### 2. Generator Agent
**Призначення:** Генерація креслень в AutoCAD

**Функції:**
- Створення P&ID символів (силоси, бункери, конвеєри)
- Малювання ліній потоку
- Розміщення міток та розмірів
- Оптимізація компоновки (мінімізація перетинів)
- Генерація LISP/Python команд для AutoCAD

**Бібліотека символів:**
- Силоси (конічне дно)
- Бункери прийому
- Норії (елеватори)
- Ланцюгові конвеєри
- Стрічкові конвеєри
- Засувки (ручні/електричні)
- Системи аспірації

### 3. Validator Agent
**Призначення:** Перевірка точності та відповідності стандартам

**Критерії валідації:**
- Точність розмірів (±0.1 мм)
- Відповідність ISO 14617 для P&ID
- Коректність зв'язків
- Відсутність перетинів без вузлів
- Наявність всіх обов'язкових міток

**Метрики якості:**
- Error rate < 1%
- Час генерації < 30 секунд
- Повнота схеми 100%

## Технічний стек

- **Python 3.12+**
- **AutoCAD 2026** (через MCP server)
- **Бібліотеки:**
  - `autocad_helper.py` - обгортка для AutoCAD MCP
  - `pdf2image` - конвертація PDF
  - `pytesseract` - OCR
  - `opencv-python` - обробка зображень
  - `networkx` - оптимізація компоновки
  - `pydantic` - валідація даних

## Стандарти та вимоги

### P&ID Symbols (ISO 14617)
- Силоси: Циліндр з конусом, діаметр пропорційний об'єму
- Конвеєри: Стрілки з підписами (T7, T8, тощо)
- Елеватори: Вертикальні лінії з позначками H5, H6
- Потоки: Червоні (прийом), сині (вивантаження)

### Шари креслення
- **EQP** - обладнання
- **FLOW** - лінії потоку
- **TEXT** - мітки та розміри
- **DIM** - розміри

### Масштаб та формат
- Масштаб: 1:100
- Формат: A1 (594×841 мм)
- Одиниці: міліметри

## Використання

```python
from grain_elevator_agent import GrainElevatorAgent

# Ініціалізація агента
agent = GrainElevatorAgent(
    autocad_helper_path="D:/autocad project/autocad-mcp/autocad_helper.py"
)

# Генерація схеми з PDF
agent.generate_from_pdf(
    input_pdf="Технологія 06.06.24.pdf",
    page=1,
    output_dwg="elevator_scheme.dwg"
)

# Або з структурованих даних
params = {
    "silos": [...],
    "conveyors": [...],
    # ...
}
agent.generate_from_params(params, "elevator_scheme.dwg")
```
